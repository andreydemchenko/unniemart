# Unnie Mart

Content strategy and automations for **Unnie Mart** (TikTok [@unniemart_](https://www.tiktok.com/@unniemart_)),
a Philippine K-pop merch group-order shop that posts in Taglish.

Goal: grow the account and sales with real, human content (no AI slop) while machines do the boring work.

## Folders

| Folder | What lives there |
|---|---|
| `research/` | Research reports (own account, videos, competitors, audience, algorithm, calendar, tools) |
| `strategy/` | The plan: content strategy, formats, weekly workflow, automation roadmap |
| `content/ideas/` | Weekly idea lists and talking points |
| `content/drafts/` | Captions and posts waiting for a human check |
| `automations/` | Scripts that do the boring work (scraping, reports, monitoring) |
| `site/` | The shop's private website (orders live from her sheet, stock, videos, tasks, docs), runs on the server: https://unniemart.159-195-15-10.sslip.io |
| `data/` | Processed data (CSV/JSON). `data/raw/` holds raw scrapes and is not committed |
